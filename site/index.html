The programme

Three days, prompt to deliverable.

Day one you learn to ask — the CTFT framework that turns a vague request into a usable draft. Day two you learn to produce — presentations, data analysis, and a prompt library you keep. Day three you build the real thing and present it. No coding, at any point.
